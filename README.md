# Taskflow

A project management tool like JIRA and Trello😂😂

Project: TaskFlow - Team Project Management System

Imagine you've just joined a software company. Your team is building a web application called TaskFlow, similar to Trello or Jira.

The application allows users to:

Create an account
Log in
Create projects
Create tasks
Assign tasks
Set due dates
Change task status
View a dashboard

The application itself is just a vehicle—the real goal is to practice GitHub workflows.

## Folder Structure

- `docs/` - Project documentation, notes, and supporting guides.
- `src/` - Source code for the application.
- `tests/` - Automated tests for the application.
- `.github/workflows/` - GitHub Actions workflow files for CI and automation.

The empty folders include a `.gitkeep` file so git tracks the directory structure even before code is added.
